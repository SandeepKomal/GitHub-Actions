# Contributing

Thanks for contributing to this GitHub Actions examples repository.

## Before opening a PR

- Keep workflows safe and self-contained.
- Never commit tokens, passwords, kubeconfigs, cloud credentials, or private keys.
- Prefer current, supported action versions.
- Use least-privilege `permissions:`.
- Explain what a workflow demonstrates and how to test it.
- Avoid examples that can accidentally deploy to a real production system.

## Pull requests

Please include:

- What changed
- Why it is useful
- How the workflow was tested
- Any required secrets or GitHub settings
