Your own fork

Public repositories run on GitHub-hosted runners at no cost.

# 1. Fork and clone the course
gh repo fork SandeepKomal/GitHub-Actions --clone
cd GitHub-Actions

# 2. Enable Actions on the fork, then push
git commit --allow-empty -m "Run CI"
git push

# 3. Watch the run
gh run watch

What is in the repository

Working workflows and deployment templates the levels use.

  • ci.yml: a Python matrix with a pip cache, pinned actions
  • security.yml: CodeQL on a schedule
  • reusable-ci.yml: a reusable workflow
  • examples/: Kubernetes, Swarm and Maven deploy templates
