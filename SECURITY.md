# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem. Report it privately: use [GitHub private vulnerability reporting](https://github.com/SandeepKomal/GitHub-Actions/security/advisories/new) if it is enabled, or contact [@SandeepKomal](https://github.com/SandeepKomal) through GitHub.

Include what you found, where (file, workflow or page), how to reproduce it and the impact you expect. You will get an answer as soon as possible; this is a free project maintained in spare time, so please allow a few days.

## Scope

- The code, scripts, workflows and examples in this repository.
- The learning site published from it on GitHub Pages.

Only the `main` branch is supported; fixes land there.

## Good practice for contributors

- Never commit passwords, tokens, private keys, cloud credentials or real environment files.
- Examples are for learning: review them before using them in production.
- The learning site loads nothing from other sites and keeps no personal data; changes must keep it that way.
